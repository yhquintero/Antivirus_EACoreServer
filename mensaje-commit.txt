Compatibilidad con Windows antiguos y Unix, temas accesibles y ayuda visual
Compatibilidad de sistemas (compat.py, main.py)
- Matriz de soporte por version de Windows con el Python maximo instalable en
  cada una: XP/2000/2003 se quedan en 3.4.4 y quedan fuera; Vista, 7 y 8.0
  solo funcionan con Python 3.8; 8.1 admite de 3.8 a 3.12.
- Windows 7 avisa del update KB2533623, sin el cual Python 3.8 no arranca.
- Familias BSD (FreeBSD, OpenBSD, NetBSD, DragonFly), Solaris/illumos y AIX
  reconocidas y degradadas a modo diagnostico en vez de fallar.
- main.py comprueba en orden interprete, sistema y privilegios antes de abrir
  la ventana, y explica por escrito por que no puede continuar.
Backend POSIX generico (usb_monitor.py)
- Enumeracion con df -kP y mount para los Unix sin backend especifico.
- Deteccion de medios extraibles deliberadamente conservadora: ante la duda la
  unidad se marca como no reparable.
Temas accesibles (temas.py)
- Cinco paletas profesionales mas la opcion de seguir al sistema.
- Color de acento personalizable que recalcula los tonos derivados y elige el
  texto por contraste, no a mano.
- Cuatro escalas de tamano de letra y seleccion de familia de fuente por
  plataforma.
- Las cinco paletas, los ocho acentos y los tintes de fila cumplen WCAG 2.1 AA;
  la de alto contraste cumple AAA.
- Modulo independiente de tkinter para poder validarlo en el CI sin pantalla.
Ayuda visual (ayuda.py, gui.py)
- Pestana Ayuda con guia paso a paso, leyenda de estados, diagrama de la firma
  del malware, notas de seguridad, preguntas frecuentes e informacion del
  sistema; exportable a texto. Accesible con F1 y Ctrl+H.
- Tooltips en botones, tablas, barra de progreso y registro, mas asistente de
  bienvenida en el primer arranque.
- Barra de estado con el sistema, la arquitectura y el nivel de soporte.
Correcciones encontradas al escribir las pruebas
- La leyenda describia estados que la pantalla nunca mostraba y faltaban dos.
  Texto, icono, color y tag salen ahora de un unico catalogo (ESTADOS_UNIDAD)
  para que no puedan volver a divergir.
- El tag "sospechosa" estaba configurado pero nunca se usaba.
- Una reparacion terminada en COMPLETADO_CON_ERRORES no se marcaba, asi que la
  tabla la mostraba como limpia y daba el trabajo por bueno.
- El log y la barra de estado imprimian la cadena de maquina del enum en vez de
  texto legible.
- Cuatro lambdas diferidas con root.after leian la variable e fuera de su bloque
  except. En Python 3 esa variable se borra al salir del bloque, asi que el
  NameError se tragaba el mensaje y el usuario no veia ningun error.
- gui.py escribia el fondo y el titulo de ventana con valores fijos, causando un
  destello de color equivocado al arrancar con un tema guardado.
- El log usaba Consolas y la interfaz Segoe UI a mano: fuentes exclusivas de
  Windows.
Pruebas y CI
- 257 pruebas (antes 54). Nuevas: compatibilidad por sistema (33), temas y
  contraste WCAG (66), contenido de ayuda y consistencia con la tabla (67),
  piso de Python 3.8 (12) y construccion real de la ventana (25).
- test_piso_python38.py valida la sintaxis con ast(feature_version=(3,8)) y
  detecta match/case, uniones PEP 604 y genericos builtin evaluados.
- CI ampliado a cinco combinaciones: Ubuntu/macOS/Windows con 3.12 mas Windows
  y Ubuntu 22.04 con 3.8, el piso real de Vista/7/8.
- En Linux se instala Xvfb y un paso falla si las pruebas de interfaz se omiten.
